## Overview
Tujuan folder Projects:
- Menyimpan proyek akhir, latihan, dan materi workshop secara terorganisir.
- Menyediakan demo yang bisa dijalankan (mis. Streamlit) dan notebook yang bisa dibuka untuk pembelajaran.
- Membuat tiap proyek self-contained: kode, notebook, gambar/asset, dan README proyek.

---

## Features
- Struktur projek yang sederhana dan konsisten.
- Demo interaktif (Streamlit) untuk beberapa proyek (lihat Final-Amarine).
- Notebook eksplorasi dan tutorial untuk Pandas, NumPy, dan eksperimen K-Means.
- Contoh penggunaan image processing + clustering (Final-Amarine).
